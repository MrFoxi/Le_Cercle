Comment jouer

Clic gauche : ouvrir une case · Clic droit : drapeau · Clic sur un chiffre entouré de ses drapeaux : ouvre ses voisins. Sur téléphone : toucher pour ouvrir, appui long (ou mode 🚩) pour le drapeau.

Chaque grille se termine par déduction : le premier clic est toujours sûr, et si jamais tu es obligé de deviner, le jeu ne te punit pas.

Une mine coûte une vie. Entre les grilles : des pièces, une amélioration à choisir, parfois la boutique. Un boss tous les 5 niveaux. Va le plus loin possible !

    Comment on joue
    • Chacun reçoit un rôle secret : 🐺 Loup-Garou, 🔮 Voyante, 🧪 Sorcière, 🏹 Chasseur ou 🧑‍🌾 Villageois.
    • La nuit, le village dort. Les loups choisissent ensemble une victime (et se parlent en secret), la voyante découvre un rôle, la sorcière peut sauver ou empoisonner.
    • Le jour, on découvre les morts, on se promène sur la place, on discute, on s'accuse… puis on vote : le plus désigné est chassé du village. Égalité : personne.
    • Le chasseur qui meurt tire une dernière flèche. Les morts deviennent des fantômes : ils voient tout mais ne parlent plus.
    • Le village gagne quand il n'y a plus de loups ; les loups, quand ils sont aussi nombreux que les autres.
    • Pour s'amuser : 1…0 emotes, clic sur un villageois pour lui lancer une tomate, une chaussure, un poisson… ou une rose.
